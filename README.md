# 🛒 Amazon Sales Data Analysis Dashboard

## 📌 Project Overview

This project is an interactive **Amazon Sales Analysis Dashboard** developed using **Power BI**. The dashboard provides valuable insights into sales performance, customer purchasing behavior, product category performance, payment preferences, delivery status, and geographical sales distribution.

The objective of this project is to demonstrate end-to-end Business Intelligence skills including **data cleaning, transformation, data modeling, DAX calculations, and dashboard development**.

## 📈 Features

### 🌍 Location-wise Sales Analysis
- Analyze total sales across different cities.
- Identify high-performing locations.

### 📦 Category & Product Analysis
- Compare sales performance across categories.
- Track product contribution within categories.
- Identify top-performing products.

### 📅 Sales Trend Analysis
- Monitor monthly sales trends.
- Compare performance across quarters.

### 💳 Payment Method Analysis
- Understand customer payment preferences.
- Analyze payment method distribution.

### 🚚 Delivery Status Monitoring
- Track Completed Orders.
- Monitor Pending Deliveries.
- Analyze Cancelled Orders.

### 🎯 Interactive Filters
Users can dynamically filter dashboard insights using:
- Category Filter
- Product Filter
- Quarter Filter
